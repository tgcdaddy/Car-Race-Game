ENDURO RETRO ROAD CHALLENGE
============================

A self-contained HTML5 retro racing game inspired by the gameplay language of 1980s arcade/home-console racers.

FILES
-----
index.html
style.css
game.js

RUN
---
Open index.html in a modern browser.

No backend, CDN, external libraries, external images, or external audio are required.

CONTROLS
--------
Desktop:
Arrow keys / WASD
UP/W    accelerate
DOWN/S  brake
LEFT/A  steer left
RIGHT/D steer right
SPACE   pause

Mobile:
Use the on-screen touch controls.

FEATURES
--------
- 10 progressive endurance days
- Increasing traffic and speed
- Procedural pseudo-3D road
- Curves and perspective
- Day / sunset / night / fog / sunrise / snow environments
- Procedural roadside scenery
- Original procedural retro sound effects using Web Audio API
- Collision feedback
- Local best score/day storage
- Fullscreen
- Responsive mobile and desktop layout
- No ads
- Offline after the files are copied locally

NOTE
----
This project uses original procedural graphics and sounds and is an independent homage to classic retro racing gameplay.
